# mararararai-mst.github.io（ドメイン直下）

GitHub Pages の `robots.txt` は **ドメインの一番上に置いたものだけ**が読まれる。
各プロジェクト（`/edu-box/` など）の中に robots.txt を置いても無視されるため、
検索に出す・出さないの制御はこのリポジトリの `robots.txt` に集約する。

## いまの方針
- 検索に出す: `/sansu-keito-tkk/`（小学校算数 アプリ系統表。TKKの無料アプリへのリンク集）
- 検索に出さない: それ以外すべて（教材リンク集・各教材アプリ・校内資料など）
  - URL を知っていれば今までどおり開ける。生徒・先生への配布リンクは動く
  - 検索エンジンの一覧には出さない

## 新しく作った教材を検索に出したくなったら
`robots.txt` に `Allow: /<リポジトリ名>/` を1行足して push する。
